# 🚀 Featured Projects

### 🏥 Hospital Management System
React + Vite, with localStorage as the primary data layer and Supabase as a sync/audit backend. Four role-based dashboards — Patient, Doctor, Receptionist, and Admin.

### 🌐 SocialSphere
A social media MVP built with plain JavaScript and Firebase (Auth, Firestore, Storage) — real-time feeds, secure access rules, and a redirect-based auth flow.

### 🧠 Forget → Remember
A spaced-repetition study app with XP, levels, and streaks, using a simplified SM-2 algorithm. Rebuilt from local-only state into a fully persistent, per-user Firebase app.
